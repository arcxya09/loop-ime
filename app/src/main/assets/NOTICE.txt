API keys are stored with Android Keystore. Personal records are encrypted locally.
With cloud speech enabled, microphone audio streams to the selected Alibaba Cloud Model Studio region.
Offline/private-field speech uses a separately downloaded model and is processed on device. Audio is not written to files.
Model weights are not bundled. Optional verified downloads come from the model author on Hugging Face.
Only explicitly enabled text AI features send eligible text to your configured HTTPS endpoint.
With AI nine-key candidates enabled, the current phone-key code, recent eligible context and permitted lexicon hints are also sent. Suggestions require a tap to commit.
