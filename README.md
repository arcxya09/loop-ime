# Loop 输入法

Android 17（API 37）及以上的原生中英 AI 输入法。版本 `0.3.1`（正式版），支持 arm64-v8a 和 x86_64。基础拼音输入安装即用；语音仅使用百炼云端，需要联网并配置独立 Key，不再包含离线语音运行库、模型或下载入口。

从 0.2.0 起使用正式版发布通道，后续不再发布 Alpha。已实现下表功能；准确率、续航、长时间语音及各厂商手机兼容性仍以设备验证为准。正式版沿用原开发证书，可从 Alpha 覆盖升级并保留数据；签名说明见 `signing/README.md`。

项目提供 GitHub Actions 自动构建与发布配置：推送到默认分支后运行完整主机测试，验证 APK 并发布带 APK、源码及校验值的 Release。接入与更新步骤见 `GITHUB_RELEASES.md`；后续维护约定见 `AGENTS.md`。

首次克隆或解压源码后，先用 Python 3.11+ 运行 `python3 scripts/materialize-dependencies.py`（Windows 可用 `python`）。它从仓库内的分块文件还原 Boost 源码包，逐块及整体核对 SHA-256，无需下载；CI 自动执行此步骤。随后可运行 Gradle Wrapper 或用 Android Studio 打开项目。

## 使用

0.3.1 按要求移除离线语音功能。保留云端语音和全部键盘功能；断网时停止录音并保留已确认文字，隐私字段禁用语音。已有 Key、词库和用户文件不自动删除，旧版关闭云端语音的偏好继续保留。

0.3.0 将 Loop 工具改为固定高度的八宫格，并增加可排序工具、单手模式、空格横滑光标、连续表情/文本编辑、可预览的剪贴板卡片、分组常用短语和深浅色适配。设置按用途分组并支持逐级返回。验证码与复制内容可在本机提取并点击填入；短信、通知需要单独开启和系统授权，系统隐藏的验证码无法保证读取。详细操作、隐私和平台边界见 [USABILITY.md](USABILITY.md)。

0.2.0 智能词频结合长期习惯、连续时间衰减和最多 4 字的前文搭配，同音词会根据已学习的上下文排序；上下文不足时回退到个人频率与近期使用，不再让最后一次选择总是占首位。选词立即学习、重开后保留，单字和九宫格同样支持；点击、空格和回车共用顺序。需开启“学习”，隐私输入和提交失败不学习；删除来源记录或遗忘词条撤回相应依据。关闭“记忆”但保留“学习”时，仍保存词频及短前文统计。算法调研与公式见 [RANKING.md](RANKING.md)。

alpha.21 不再在空输入时显示常用词；联想只提供后续内容，并过滤重复输入。候选占满顶部宽度，下拉展开，长按候选或拼音可打开分词、工具和提示操作菜单。九宫格拼音不再带数字编码。英文与符号键盘的按键边界与九宫格统一，中英切换位于句号右侧。

长按九宫格数字键输入 1–9，长按“123”输入 0。英文键盘长按 `qwertyuiop` 输入 `1234567890`；`asdfghjkl` 对应 `@ # $ % & * ( ) -`，`zxcvbnm` 对应 `! " ' : ; ? /`，键帽角标显示对应字符。长按空格仍为语音输入。

alpha.20 统一固定键盘高度：语音结束、识别失败、下载模型等提示使用顶部工具栏；云端候选与本地候选共用横栏，可滑动或展开选择。拼音显示优先，需要处理的提示可长按工具图标操作；普通提示自动收起。九宫格、全键盘、符号和工具面板切换保持同一高度，语音出错后恢复个人候选。

alpha.19 恢复输入中的拼音显示：全键盘显示当前拼音，九键显示 Rime 首候选参考读音及当前编码；点击可查看完整内容。拼音和候选共用原有工具栏高度。修复选词后语音引导反复增加提示行的问题。

alpha.18 将九宫格和全键盘切换为内置白霜中文词库（约 65.3 万条字词/读音记录）。首次打开中文键盘会部署新词库，请等待“拼音已就绪”；个人词库和旧数据保留。AI 候选失败不再新增提示行，工具图标短暂变色，长按可查看原因。

alpha.17 补齐 v1/v2/v3 签名以改善安装器证书识别兼容性，沿用原证书，可直接覆盖安装。MagicOS 11 的实装结果仍待验证，详见 `TESTING.md`。

alpha.16 新增 GitHub 自动更新：设置首页 → 软件更新。默认每日检查并通过 Wi-Fi 下载，校验后由系统确认安装；可关闭自动更新、切换预发布通道或手动下载。旧版本需先手动覆盖安装这一版。详见 `UPDATES.md`。

alpha.15 修复了光标定位、单位与否定词纠错、回车动作、语音热词隐私、旧备份词频、分页队列、当前剪贴板和英文语音分段问题。设置中的个人词库支持分页和直接修改读音；AI 设置可选择关闭纠错、只显示建议或保守自动纠错。键盘 Loop 工具可对当前应用开启长期隐私输入，AI 自动修改后的状态栏可直接点击撤销。

备份页可先预览合并结果；模型页可查看导入模型空间并清理未选用的旧模型。语音识别期间状态栏显示系统当前音频输入路线，暂不提供手动切换路线。完整改动与验证范围见 `CHANGELOG.md`、`TESTING.md` 和 `ROADMAP.md`。

1. 安装交付的 `Loop-IME-0.3.1.apk`。系统必须是 Android 17 / API 37+，并允许本次 APK 安装。
2. 打开“Loop 输入法”，依次点击“启用 Loop”和“选择 Loop”。
3. 在“AI 与语音”→“云端语音服务”中允许麦克风，配置百炼 Key 并启用云端语音；回到普通文本框长按空格，出现“正在听”后说话，松手结束。也可点击顶部麦克风图标进入连续模式，再点方形停止图标结束。
4. 要使用文本 AI，打开“AI 与语音”→“AI 连接与实时纠错”，填写 **DeepSeek 开放平台 API Key**，点击“保存 Key 并测试连接”，再开启“云端文本 AI”，保留“AI 九宫格候选”开关。默认地址和 DeepSeek Flash 模型已内置。其他服务仍可通过“高级设置：自定义 API”配置。
5. 要使用云端语音，在语音设置填写对应地域的百炼 Key，点击“保存并测试百炼连接”。保存后启用云端语音；断网时停止录音，联网后可重新开始。百炼 Key 与 DeepSeek Key 分开保存。
7. 按需开启输入记忆、持续学习和剪贴板；导入通讯录需在手机上授权。历史聊天、其他输入法和应用内未通过 Loop 输入的内容不会被读取。

中文默认使用简体九宫格，工具栏内同时显示拼音/编码和候选词；可在左上角 Loop 工具中选择“切换为 26 键全键盘”并记住选择；英文保持 QWERTY。长按空格说话、松手结束；切换其他输入法使用系统自带的切换按钮。短按空格选择首候选；中文组合状态下，回车先提交组合。九宫格按参考图排列：左侧标点与符号，中间字母与数字角标，右侧删除、重输和大回车，底部数字、宽空格、中英切换；“重输”只清除尚未提交的拼音。组合输入时，“分词”位于顶部；光标、表情和“撤销 AI”收在左上角 Loop 工具中。程序不再绘制底部切换栏或地球图标。设置页的试写框支持离线拼音，不启用语音、不记录、不调用云端 AI。

## 诊断日志

遇到问题后，打开设置首页的“诊断日志：复制 / 导出”。先重现一次失败，再导出 TXT，或复制最近日志。日志无需读取或解密原数据库，不收集 Key、输入内容和联系人姓名。详见 `DIAGNOSTICS.md`。

数据库打开失败时，AI 九宫格可只凭当前编码提供候选。设置首页新增“数据库检查与恢复”，支持在副本上尝试旧库恢复，或经明确选择启用独立新库并保留旧文件和 Key。具体操作及旧记忆的恢复边界见 `DATABASE_RECOVERY.md`。

| 输入记忆 | 普通字段中 Loop 提交的文本片段；独立加密待写日志、按版本合并并重试；本地加密；无自动到期删除；检索、分页、逐条删除、全部清空 |

| 词库管理 | 手工添加、修改拼音、多音字修正、词条遗忘；删除记忆撤回相应来源贡献；遗忘词不会自动学回 |
| 通讯录 | 只查询联系人显示姓名并生成拼音；不查询电话、邮箱或照片列；导入词条仅本地；可移除所有通讯录来源 |
| 剪贴板 | 默认关闭；仅键盘可见的普通字段采集纯文本；跳过系统标记敏感内容；未固定内容保留 7 天、最多 200 条；固定与删除 |
| 旋转锁 | 用户开启并授予“修改系统设置”权限后，临时关闭自动旋转，结束后恢复；恢复日志支持异常后下次启动修复 |
| 数据备份 | SAF 文件选择；独立密码；PBKDF2-HMAC-SHA256 + 分记录 AES-256-GCM；流式读取；错误密码、篡改、截断导致整次恢复回滚；不导出 API Key |
| AI 配置备份 | 单独导出全部文本 AI 配置、北京/新加坡百炼 Key、选用地域和输入设置；PBKDF2-HMAC-SHA256（210000 次）+ AES-256-GCM，密码加密文件可在卸载或换机后恢复；错误密码、篡改、截断不会替换原配置 |
| 自定义 ASR 模型 | 导入固定结构的模型 ZIP，校验路径、文件数、大小、SHA-256；仅支持与推荐模型接口一致的流式 Zipformer 中英 transducer |

“完整记忆”指 Loop 发出的提交文本片段，不是按键录像，也不代表宿主应用已经发送了消息。组合中的拼音、未稳定的语音 partial、录音、密码及隐私字段不作为历史保存。编辑当前片段会更新该片段；应用主动替换的旧文字和其他输入法输入的内容无法完整追踪。

## 数据边界

- 云端文本 AI、百炼云端语音、完整记忆、剪贴板分别在设备上启用。密码框、隐私模式和 `IME_FLAG_NO_PERSONALIZED_LEARNING` 字段禁用语音，排除记忆、学习及云端请求。
- 覆盖安装沿用原签名和包名，已保存的 Key 保留；配置索引丢失时从加密记录找回，读取异常明确报错。卸载会清除数据，需提前单独导出 AI 配置备份；已删除且没有备份的 Key 无法恢复。
- API Key 和配置仍由 Android Keystore 的 AES-256-GCM 密钥保护。新版密钥不要求系统认证令牌，由应用在每次读取和保存前检查用户存储已解锁、设备未锁定；没有明文保存回退。SQLCipher 使用随机数据库密钥，密钥由 Keystore 包装。系统云备份和设备迁移已排除应用数据。
- 新旧加密记录有版本区分。可读的旧配置及数据库密钥自动重新包装，值保持一致；暂不可读的旧记录和旧 alias 保留，API 页可重新填写 Key 独立保存。不会在旧数据库密钥读取失败时创建替代密钥。
- 麦克风仅在用户明确长按触发语音或点击麦克风、键盘可见且有权限时采集；正常短按空格不录音。录音从语音开始即进入内存缓冲，识别引擎异步准备。启用百炼后，音频实时发送到所选地域；本地模式音频不上传。音频不写文件，启动音频、未发送音频和未确认尾部仅在内存中保留，合计最多 120 秒，结束或取消即清除；达到上限明确停止，不静默丢弃。切换输入框、隐藏键盘、熄屏或无法继续处理时停止采集。
- 文本 AI 只获得当前普通输入的有限文本，以及允许云端的词条提示。开启 AI 九宫格候选时还发送当前按键编码，详细范围见 `T9_CANDIDATES.md`。通讯录与手动标记的本地词条会阻止含这些词的请求。旧的仅本地记忆不会被当作云端上下文检索；用户新的独立输入按当前授权处理。
- 从记忆、剪贴板或仅本地个人候选插入内容后，本输入框暂停后续 AI，以免将本地材料夹带上传。未知宿主行为无法安全定位时，放弃自动修改。
- 保存队列有上限；输入编辑先写入独立加密日志，再提交数据库。队列满或数据库失败会保留日志并重试，进程重启后补写；显式删除会同时取消待写记录。加密日志落盘前进程被杀、密钥不可用或磁盘耗尽时，最后一小段仍可能无法保存。

## 开发与构建

依赖：JDK 21（包含 Android 17 View 回归测试；仅编译 APK 可用 JDK 17）、Android SDK Platform 37.0、Build Tools 37.0.0、NDK r28c（仅重编自有 JNI 桥需要）。工程使用 AGP 9.1.1、Gradle Wrapper 9.3.1 及其内置 Kotlin 支持。首次构建需要正常访问 Google Maven 与 Maven Central。

源码包包含两个架构的 Rime 原生库、自有 JNI 桥和词典。语音不再依赖本地识别库或模型；`third_party/checksums.json` 保留当前原生依赖的 SHA-256。

```bash
# 配置 ANDROID_HOME 指向本机 SDK，或自行建立 local.properties（sdk.dir=...）。
python3 scripts/materialize-dependencies.py
./gradlew :app:assembleRelease
./gradlew :app:testDebugUnitTest :app:lintDebug

# 可选：用 NDK 重编 Loop 的 Rime JNI 桥。
export ANDROID_NDK_ROOT=/path/to/android-ndk-r28c
./scripts/build-native.sh

# 连接专用 Android 17+ 测试设备，运行数据库及密钥检查；不需要语音模型。
./gradlew :app:connectedDebugAndroidTest
```

输出：`app/build/outputs/apk/release/app-release.apk`。可用 `-PloopBuildRoot=/tmp/loop-build` 将中间构建结果放到独立目录。

## 当前边界

- 正式版发布范围仍不包括商业输入法级的模糊拼音、滑行输入、任意局部拼音改写、复杂皮肤、丰富表情、蓝牙路由面板或所有编辑器适配。
- 拼音个人词条仅在完整拼音或完整九键编码、尾部光标、没有内部分段确认时替换整段，避免重复上屏。Rime 自有用户词频学习关闭，个人学习归 Loop 管理。
- 模型不是动态训练；“持续学习”指词库、频次与热词更新。推荐模型未针对你的声音做训练，也不自动录音用于训练。
- 记忆检索是数据库的分页子串搜索，没有实现向量检索或海量记录全文索引。数据保留取决于设备存储空间。中文关键词质量需要使用反馈；AI 词条提取是由系统安排的后台任务。
- 自定义 API 仅支持 Chat Completions 兼容格式，不直接支持 Anthropic 原生 Messages、Gemini 原生协议或任意流式 WebSocket 协议。云端 ASR 独立接入百炼，协议和行为见 `CLOUD_ASR.md`。
- 停顿标点目前是本地句末规则，不能替代专业标点恢复模型。热词每次最多 64 个，词库大于此数量时按权重取子集。
- Android 系统或宿主应用可能覆盖旋转设置；恢复在语音结束和下次应用启动时执行，强制停止后不能保证立即修复。
- 主应用服务包含少量最终 InputConnection 锚点读取；复杂宿主可能响应缓慢。语音、输入时延与发热必须在目标真机测量。
- 卸载将丢失本机 Keystore 密钥；请分别导出数据备份和 AI 配置备份。当前版本的签名面向内部测试。

本次九宫格候选更新及之前的功能更新见 `CHANGELOG.md`。中文九键例如输入 `64426` 可选“你好”、`94664486` 可选“中国”；“分词”插入音节分隔符。已有联系人和手动词条保留其原始写法，简体默认作用于内置中文候选。键盘处理导航栏、输入法切换栏（caption bar）、手势安全区和横屏边缘遮挡，窗口与按键内容只进行一次避让。

开源许可和固定版本来源见 `THIRD_PARTY_NOTICES.md`。修复清单见 `FIXES.md`，验证结果见 `TESTING.md`。


## alpha.14 候选与词频

候选栏右侧箭头可展开所有候选，也可以在候选栏向下滑动。展开后上下滚动，到底部继续加载；点击箭头收起。云端建议单独显示，点击后才输入。本地候选与空格默认选词不随云端结果改变。

通讯录和个人词库现在支持拼音前缀补全；同音词按选词累计的权重排序。设置 → 输入记忆与词库 → 个人词库可查看权重。需要开启“持续学习词库”；隐私模式或禁止个性化学习的输入框不会累计。仍无法打开旧库时，请先使用“数据库检查与恢复”，查看诊断日志。
